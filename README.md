# QR Code Exhibition System

A MERN stack QR Code Data Collection System for exhibition events.

## Structure

```
/
├── server/   ← Express.js backend  (deployed to Vercel)
└── client/   ← React + Vite frontend (deployed to Netlify)
```

## Quick Start

```bash
# Backend
cd server && npm install && npm run dev

# Frontend
cd client && npm install && npm run dev

# Seed admin (first time only)
cd server && npm run seed
```
